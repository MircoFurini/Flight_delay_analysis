# Flight_delay_analysis

## 🎯 Project Overview

This project analyzes the punctuality of domestic flights across the United States between **2013 and 2023**, examining how flight delays are distributed across airlines, airports, and underlying causes.

By breaking down delay metrics across multiple dimensions, the analysis distinguishes between **controllable inefficiencies** and **external disruptions**.

These patterns are evaluated through exploratory and geospatial analysis across specific carriers and key domestic hubs.

### 💼 Business & Operational Goal
The insights generated by this project are designed to assist **airline operations analysts** in identifying critical routes, airlines and airports that justify targeted investments in operational efficiency and scheduling resilience.

## 🚀 Setup & Execution

1. **Clone the repository:**
    ```bash
    git clone https://github.com/MircoFurini/Flight_delay_analysis.git
    cd Flight_delay_analysis
    ```

2. **Install requirements:**
    ```bash
    pip install -r requirements.txt
    ```

3. **External Data Requirement:**
    Due to file size constraints, `airports.csv` is not tracked in this repository. Before running the project:
    * Download [airports.csv](https://davidmegginson.github.io/ourairports-data/airports.csv).
    * Place the file in the project root directory.

4. **Launch the analysis:**
    * Open and run the `.ipynb` notebook in your preferred environment (VS Code or Jupyter Notebook).
